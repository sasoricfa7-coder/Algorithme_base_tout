Feuille de route pour interpreteur.pyLe rôle de l'interpréteur est d'être un parcoureur d'AST (Pattern Visitor). Il va recevoir le nœud racine Algorithme produit par le parseur/analyseur sémantique et exécuter les instructions une par une.Voici la structure bloc par bloc à construire dans ton fichier.1. Les éléments à importerAu sommet de ton fichier interpreteur.py, tu auras besoin de :L'environnement : from environnement import EnvironnementLa fonction de gestion des erreurs : from erreur import erreurLes classes de nœuds de ton AST (depuis ton fichier AST, ex: Algorithme, Affectation, Ecrire, Lire, Si, Pour, Nombre, Identifiant, OperationBinaire, etc.).2. Un outil spécial : Le signal de retour (SignalRetour)En Python, quand une fonction EVA rencontre une instruction Retourne, il faut immédiatement stopper l'exécution de cette fonction et transmettre la valeur calculée à l'appelant.Le moyen le plus propre en Python est de créer une exception personnalisée avant la classe Interpreteur :Rôle : Cette classe hérite de Exception.Attribut : Elle contient uniquement la valeur retournée par l'instruction Retourne.Usage : Quand l'interpréteur croise une instruction Retourne, il lève (raise) cette exception. Quand l'interpréteur appelle une fonction, il attrape (try...except) cette exception pour récupérer la valeur.3. La classe Interpreteur : Initialisation et point d'entréeLes attributs de l'InterpréteurDans son constructeur (__init__) :env_global : Une instance de Environnement() qui servira pour le corps principal du programme.env_courant : Un pointeur vers l'environnement actif. Au départ, self.env_courant = self.env_global.fonctions : Un dictionnaire {nom_fonction: noeud_AST_fonction} pour retrouver facilement la définition d'une fonction lors d'un appel.procedures : Un dictionnaire {nom_procedure: noeud_AST_procedure} pour les procédures.Le point d'entrée : interpreter(self, ast: Algorithme)C'est la méthode principale appelée depuis l'extérieur. Elle déroule le programme en 3 étapes chronologiques :Enregistrement des sous-programmes :Elle parcourt ast.fonctions et remplit le dictionnaire self.fonctions avec le nom et le nœud de chaque fonction.Elle fait de même pour ast.procedures.Exécution des déclarations globales :Elle parcourt ast.declarations.Pour chaque déclaration, elle l'exécute dans self.env_courant (qui est env_global).Exécution du corps principal :Elle parcourt la liste d'instructions ast.corps.Pour chaque instruction, elle appelle la méthode executer_instruction(inst).4. Le moteur d'exécution des instructions : executer_instruction(self, inst)Cette méthode reçoit un nœud d'instruction et utilise isinstance pour déterminer quelle action réaliser :DeclarationVariable / DeclarationConstante :Évalue la valeur initiale si elle existe (ou met une valeur par défaut comme 0 ou "").Appelle self.env_courant.definir(nom, valeur).Affectation :Évalue l'expression située à droite (inst.valeur).Si la cible est un Identifiant simple : appelle self.env_courant.modifier(cible.nom, valeur_evaluee).Si la cible est une Indexation (tableau) : met à jour la case spécifique dans le tableau stocké en mémoire.Ecrire :Évalue chaque expression présente dans la liste inst.arguments.Affiche les résultats dans la console via print(...).Lire :Utilise input() de Python pour demander une valeur dans le terminal.Convertit la saisie (chaîne) vers le type réel de la variable (entier, réel, booléen).Enregistre la valeur saisie avec self.env_courant.modifier(...).Si :Évalue la condition (inst.condition).Si le résultat est vrai (True), parcourt et exécute chaque instruction de la liste inst.alors.Sinon, si un bloc sinon existe, parcourt et exécute chaque instruction de inst.sinon.Pour :Évalue la valeur de début, de fin, et de pas.Initialise la variable d'indice dans self.env_courant.Boucle (while en Python) tant que la variable n'a pas dépassé la fin, et exécute le corps de la boucle à chaque itération.TantQue / Repeter :Boucle classique en Python évaluant la condition à chaque passage pour exécuter le corps.Retourne :Évalue l'expression de retour.Lève le signal d'interruption : raise SignalRetour(valeur_evaluee).5. Le moteur d'évaluation des expressions : evaluer_expression(self, expr)Cette méthode prend un nœud d'expression et renvoie une valeur réelle (un nombre, un booléen, une chaîne) :Littéraux (Nombre, ChaineCaractere, Booleen, Caractere) :Renvoie directement la valeur contenue dans le nœud (expr.valeur).Identifiant :Interroge la mémoire : return self.env_courant.obtenir(expr.nom).OperationBinaire :Évalue le côté gauche (gauche = self.evaluer_expression(expr.gauche)).Évalue le côté droit (droite = self.evaluer_expression(expr.droite)).Effectue l'opération selon le symbole :+, -, *, /div $\rightarrow$ division entière gauche // droitemod $\rightarrow$ modulo gauche % droite^ $\rightarrow$ puissance gauche ** droite=, <>, <, >, <=, >= $\rightarrow$ comparaisons ==, !=, etc.et, ou $\rightarrow$ and, orOperationUnaire :Évalue l'opérande et applique - ou not.AppelFonction / AppelInstruction (Procédures) :Évalue tous les arguments passés à la fonction dans l'environnement courant.Retrouve le nœud de la fonction dans self.fonctions[expr.nom].Sauvegarde l'ancien environnement (ancien_env = self.env_courant).Crée un nouvel environnement étanche pour la fonction (env_fonction = Environnement(parent=None)).Bascule sur cet environnement (self.env_courant = env_fonction).Lie chaque paramètre de la fonction à sa valeur évaluée (self.env_courant.definir(param.nom, val)).Exécute les déclarations locales de la fonction.Exécute le corps de la fonction dans un bloc try...except SignalRetour:Si SignalRetour est attrapé $\rightarrow$ extrait la valeur de retour.Sinon (si procédure ou pas de retour) $\rightarrow$ valeur = None.Restaure l'ancien environnement (self.env_courant = ancien_env).Renvoie la valeur calculée.
