================================================================================
               GUIDE DE SYNCHRONISATION GIT ENTRE DEUX PC LOCAUX
                            (Zorin OS - Réseau Wi-Fi)
================================================================================
  Auteur  : sasori
  Version : 1.0
  Date    : Novembre 2026
  But     : Transférer les commits du PC Secondaire vers GitHub via le
            PC Principal, SANS exposer la clé GitHub sur le PC Secondaire.
================================================================================

  +----------------------------------------------------------------------+
  |  ARCHITECTURE DU FLUX                                                |
  +----------------------------------------------------------------------+
  |                                                                      |
  |   [ PC SECONDAIRE ]  ---- SSH (LAN) ---->  [ PC PRINCIPAL ]  ---->  |
  |     (Développement)                          (Clé GitHub)      |     |
  |                                                                 |     |
  |                                                                 v     |
  |                                                          [ GITHUB ]   |
  |                                                                      |
  |  * Le PC Secondaire ne parle JAMAIS à GitHub.                       |
  |  * Le PC Principal est le seul à avoir la clé et l'accès Internet.  |
  +----------------------------------------------------------------------+


================================================================================
  ÉTAPE 1 : PRÉPARATION DU PC PRINCIPAL (LE SERVEUR)
================================================================================

  Rôle : Recevoir les commits et les publier sur GitHub.

  ----------------------------------------------------------------------------
  1.1  Installer et activer le serveur SSH
  ----------------------------------------------------------------------------
  Ouvrir un terminal et exécuter :

      sudo apt update
      sudo apt install openssh-server -y
      sudo systemctl enable ssh
      sudo systemctl start ssh

  Vérifier que le service tourne :
      systemctl status ssh
  (Doit afficher "active (running)" en vert).

  ----------------------------------------------------------------------------
  1.2  Trouver l'adresse IP locale du PC Principal
  ----------------------------------------------------------------------------
  Exécuter :

      hostname -I

  Noter l'adresse affichée (exemple : 192.168.11.117).
  >>> IP DU PC PRINCIPAL : __________________________

  ----------------------------------------------------------------------------
  1.3  Créer le dépôt "pont" (bare repository)
  ----------------------------------------------------------------------------
  C'est une "boîte aux lettres" Git. Elle ne contient pas les fichiers
  de travail, uniquement l'historique.

      cd ~/mon_langage
      git init --bare ~/depot_serveur.git

  Le dossier ~/depot_serveur.git est maintenant créé.


================================================================================
  ÉTAPE 2 : CONFIGURER LA CONFIANCE SSH (PC SECONDAIRE -> PC PRINCIPAL)
================================================================================

  Rôle : Permettre au PC Secondaire de se connecter sans mot de passe.

  ----------------------------------------------------------------------------
  2.1  Générer une clé SSH sur le PC Secondaire
  ----------------------------------------------------------------------------
  Sur le PC SECONDAIRE, exécuter :

      ssh-keygen -t ed25519 -C "pc_secondaire"

  Appuyer sur ENTREE à toutes les questions.
  (Laisser la passphrase vide pour simplifier, ou en mettre une).

  ----------------------------------------------------------------------------
  2.2  Copier la clé vers le PC Principal
  ----------------------------------------------------------------------------
  Toujours sur le PC SECONDAIRE, exécuter :

      ssh-copy-id sasori@<IP_DU_PC_PRINCIPAL>

  Remplacer <IP_DU_PC_PRINCIPAL> par l'adresse notée à l'étape 1.2.
  Exemple : ssh-copy-id sasori@192.168.11.117

  Saisir le MOT DE PASSE DE SESSION du PC Principal quand demandé.
  Résultat attendu : "Number of key(s) added: 1"

  ----------------------------------------------------------------------------
  2.3  Tester la connexion
  ----------------------------------------------------------------------------
      ssh sasori@<IP_DU_PC_PRINCIPAL>

  Si la connexion s'établit sans mot de passe (ou avec la passphrase de
  la clé), c'est bon. Taper "exit" pour revenir.


================================================================================
  ÉTAPE 3 : CONNECTER LE PC SECONDAIRE AU DÉPÔT PONT
================================================================================

  Sur le PC SECONDAIRE, dans le dossier de projet :

  ----------------------------------------------------------------------------
  3.1  Ajouter le PC Principal comme "remote"
  ----------------------------------------------------------------------------
      git remote add pc_principal ssh://sasori@<IP_DU_PC_PRINCIPAL>/home/sasori/depot_serveur.git

  Exemple :
      git remote add pc_principal ssh://sasori@192.168.11.117/home/sasori/depot_serveur.git

  ----------------------------------------------------------------------------
  3.2  Envoyer les commits vers le PC Principal
  ----------------------------------------------------------------------------
      git push pc_principal main


================================================================================
  ÉTAPE 4 : POUSSER VERS GITHUB (PC PRINCIPAL)
================================================================================

  Sur le PC PRINCIPAL :

  ----------------------------------------------------------------------------
  4.1  Récupérer les commits du dépôt pont
  ----------------------------------------------------------------------------
      cd ~/mon_langage
      git pull ~/depot_serveur.git main

  ----------------------------------------------------------------------------
  4.2  Publier sur GitHub
  ----------------------------------------------------------------------------
      git push origin main


================================================================================
  FLUX DE TRAVAIL QUOTIDIEN (RÉSUMÉ)
================================================================================

  +----------------------------------------------------------------------+
  |  PC SECONDAIRE (Développement)                                       |
  +----------------------------------------------------------------------+
       git add .
       git commit -m "Mon message"
       git push pc_principal main

  +----------------------------------------------------------------------+
  |  PC PRINCIPAL (Publication)                                          |
  +----------------------------------------------------------------------+
       git pull ~/depot_serveur.git main
       git push origin main

  +----------------------------------------------------------------------+
  |  RÉCUPÉRER LES NOUVEAUTÉS DE GITHUB SUR LE PC SECONDAIRE             |
  +----------------------------------------------------------------------+
       1. PC Principal  : git pull origin main
                          git push ~/depot_serveur.git main
       2. PC Secondaire : git pull pc_principal main


================================================================================
  DÉPANNAGE (TROUBLESHOOTING)
================================================================================

  [ERREUR]  "Permission denied (publickey)"
  -> La clé SSH n'est pas installée sur le PC Principal.
  -> Refaire l'étape 2.2 (ssh-copy-id).

  [ERREUR]  "Could not resolve hostname" ou "Connection refused"
  -> L'IP a changé (redémarrage du routeur).
  -> Vérifier l'IP avec "hostname -I" sur le PC Principal.
  -> Mettre à jour le remote :
       git remote set-url pc_principal ssh://sasori@<NOUVELLE_IP>/home/sasori/depot_serveur.git

  [ERREUR]  "fatal: refusing to merge unrelated histories"
  -> Les deux dépôts n'ont pas d'ancêtre commun.
  -> Utiliser : git pull pc_principal main --allow-unrelated-histories

  [ERREUR]  "authorized_keys" introuvable sur le PC Principal
  -> ssh-copy-id a échoué.
  -> Vérifier que PasswordAuthentication est à "yes" dans
     /etc/ssh/sshd_config sur le PC Principal, puis :
       sudo systemctl restart ssh
     et relancer ssh-copy-id.

  [ERREUR]  Conflit de fusion (merge conflict)
  -> Les mêmes fichiers ont été modifiés sur les deux PC.
  -> Ouvrir les fichiers en conflit, choisir les bonnes lignes,
     puis : git add <fichier> && git commit


================================================================================
  NOTES DE SÉCURITÉ
================================================================================

  * L'authentification par mot de passe reste ACTIVE sur le PC Principal.
    C'est acceptable sur un réseau domestique de confiance.
  * Pour la désactiver plus tard (une fois la clé SSH validée) :
        sudo nano /etc/ssh/sshd_config
        -> PasswordAuthentication no
        sudo systemctl restart ssh
  * La clé GitHub ne réside QUE sur le PC Principal.
